# 나이스(NEIS) 출결 자동 입력 프로그램 (v2.0)

> 초·중·고등학교 담임교사의 반복적인 출결 입력을 돕기 위한 **나이스(NEIS) 일일 출결 자동 입력 RPA 도구**입니다.  
> 엑셀 파일에 기록된 학생들의 출결 내역을 읽어 나이스 웹 화면에 사람 대신 안전하고 정확하게 입력합니다.

---

## 📌 주요 특징 및 안전 설계

- **새로운 교시별 엑셀 양식 완벽 지원**:
  - `일자 | 학번 | 교시 | 출결구분 | 상태분류 | 시스템등록일시` 양식을 지원합니다.
  - 한 학생의 여러 교시 기록(예: 3~6교시 조퇴, 5~7교시 결과/결석 등)을 자동으로 묶고, 나이스 열 순서(`조회 → 1교시 … 7교시 → 종례`)로 정렬하여 처리합니다.
- **키보드 보안 프로그램 충돌(BSOD) 방지**:
  - 나이스 키보드 보안 프로그램(커널 드라이버)과의 충돌로 인한 블루스크린(`IRQL_NOT_LESS_OR_EQUAL`)을 방지하기 위해 키보드 가상 입력 대신 **브라우저 네이티브 JavaScript DOM 주입 방식**을 기본으로 사용합니다.
- **날짜 오입력 방지 (교차 검증)**:
  - 날짜 이동 후 화면 상단 제목(예: `2학년 2반 2026.11.09. Total 26`)에 표시된 날짜가 목표 날짜와 완전히 일치할 때만 작업을 진행합니다.
- **교시칸 1회 클릭 및 안전 확인**:
  - 교시칸의 체크/해제 번복을 방지하기 위해 마우스 좌표로 정확히 1회 클릭하며, 이미 체크('/')된 경우 누르지 않고, 반응이 없더라도 절대 재클릭하지 않습니다.
- **테스트 모드 기본 지원**:
  - 프로그램 실행 시 기본적으로 **테스트 모드**가 켜져 있어, 실제 반영(`적용`) 대신 `닫기`를 누르고 교시칸을 누르지 않은 채 안전하게 사전 시뮬레이션을 할 수 있습니다.
- **CDP 브라우저 연동 방식**:
  - 인증서 로그인을 프로그램이 자동화하지 않고 사용자가 직접 안전하게 로그인한 뒤, 해당 브라우저 세션에 연결하여 작업합니다.
- **상세 로그 및 결과 CSV 자동 생성**:
  - 모든 단계 로그(`run.log`)는 즉시 디스크에 동기화(`os.fsync`)되며, 처리 결과가 `처리결과.csv`(`UTF-8 BOM`)로 저장됩니다.

## 📋 지원 엑셀 양식 안내

### 1. 열 구성
머리글 행을 자동으로 감지하므로 열의 위치나 순서가 달라도 유연하게 인식합니다.
- **일자**: `2026-11-05`, `2026.11.05`, 엑셀 날짜형 모두 지원
- **학번**: `17`, `9` (반 번호) 또는 `20917` (3자리 이상일 경우 끝 2자리를 번호로 파싱, 앞자리는 학년·반 로그 기록)
- **교시**: `조례` (나이스 '조회' 열에 대응), `1교시` ~ `7교시`, `종례`
- **출결구분**: `인정결`, `병지각`, `인정조퇴`, `미인정결과` 등
- **상태분류**: `결석류`, `지각류`, `조퇴류`, `결과류` (출결구분 검증용 보조 데이터)

### 2. 출결구분 해석 및 자동 처리 규칙
| 구분 (접두사) | 종류 (접미사) | 입력 방식 및 교시칸 처리 |
| :--- | :--- | :--- |
| **병** → 질병<br>**인정** → 출석인정<br>**미인정/무단** → 미인정<br>**기타** → 기타 | **지각** | `[마감]`칸 팝업 입력 → 교시 목록 중 **마지막 교시** 1회 클릭<br>*(예: [조회, 1교시] → 1교시 클릭)* |
| ↑ 동일 | **조퇴** | `[마감]`칸 팝업 입력 → 교시 목록 중 **첫 교시** 1회 클릭<br>*(예: [3, 4, 5, 6교시] → 3교시 클릭)* |
| ↑ 동일 | **결석** | `[마감]`칸 팝업 입력 (교시칸 클릭 없음) |
| ↑ 동일 | **결과** | 교시 목록의 각 교시칸을 직접 클릭하여 팝업 입력 |

## 🚀 사용 방법

### 1단계: 브라우저 실행 및 로그인
1. 프로그램을 실행합니다.
2. 상단에서 사용할 브라우저(**Chrome** 또는 **Edge**)를 선택하고 **`[1. 전용 브라우저 실행]`** 버튼을 클릭합니다.
3. 전용 브라우저 창이 열리면, **인증서로 나이스에 로그인**한 후 **`[일일 출결 관리]`** 화면으로 이동합니다.

### 2단계: 엑셀 파일 선택 및 검사
1. **`[파일 찾기...]`** 버튼을 클릭하여 출결 엑셀 파일을 선택합니다.
2. *(선택사항)* 엑셀에 사유가 없는 경우 팝업에 공통으로 입력할 **기본 사유**를 입력할 수 있습니다.
3. **`[엑셀 검사 및 미리보기]`** 버튼을 클릭합니다.
   - 몇 개의 엑셀 행이 몇 명의 학생 기록으로 묶였는지, 교시 목록과 클릭 대상이 올바른지 로그 창에서 확인합니다.

### 3단계: 자동 입력 시작
1. 처음 실행 시에는 **`[✓] 테스트 모드`**가 체크된 상태에서 **`[2. 자동 입력 시작]`**을 누릅니다.
   - 팝업이 올바르게 채워지고 닫히는지, 학생 번호가 올바르게 찾아지는지 확인합니다.
2. 테스트가 정상이면, **`[ ] 테스트 모드`** 체크를 해제하고 **`[2. 자동 입력 시작]`**을 눌러 실제 나이스에 입력을 반영합니다.
3. 필요 시 각 날짜 처리가 끝날 때마다 상단 **[저장]** 버튼을 자동 클릭하도록 옵션을 켤 수 있습니다.

### 4단계: 결과 확인
- 작업이 끝나면 **`[로그 폴더 열기]`** 버튼을 눌러 결과 폴더로 이동합니다.
- `처리결과.csv`: 각 학생별 처리 상태(`완료`, `실패`, `건너뜀`, `엑셀오류`)와 메시지 확인
- `run.log`: 단계별 상세 로그
- `*.png`: 교시 클릭 전후 및 오류 발생 시 자동 캡처된 스크린샷

## 🛠️ 개발 및 빌드 방법

### 1. 개발 환경 요구사항
- Python 3.10 이상
- Windows 10 / 11

### 2. 가상환경 세팅 및 라이브러리 설치
```powershell
pip install -r requirements.txt
```

### 3. 프로그램 실행
```powershell
python neis_attendance_rpa.py
```

### 4. 단위 테스트 실행 (엑셀 파서 및 해석 검증)
```powershell
python test_excel_parser.py
```

### 5. Windows용 단일 실행 폴더(exe) 빌드
프로젝트 루트의 `build.bat`을 실행하거나 아래 명령어를 입력합니다:
```cmd
pyinstaller --onedir --noupx --windowed --collect-all playwright --name NeisAttendanceRPA neis_attendance_rpa.py
```
빌드가 완료되면 `dist\NeisAttendanceRPA\NeisAttendanceRPA.exe`가 생성됩니다. (파이썬이 설치되지 않은 교사용 PC에서도 바로 실행 가능)

## 🤖 GitHub Actions 자동 빌드

본 저장소에는 `.github/workflows/build-exe.yml`이 포함되어 있습니다.  
GitHub 저장소에 코드를 푸시(`git push`)하면 **GitHub Actions가 Windows 환경에서 자동으로 실행 파일을 빌드**하여 아티팩트(`Artifacts`)로 업로드해 줍니다. 별도의 로컬 빌드 환경이 없어도 다운로드하여 바로 사용할 수 있습니다.

## ⚠️ 주의사항

1. **엑셀 파일 열림 방지**: 엑셀 파일이 열려 있으면 동시 접근이 제한되므로, 반드시 엑셀을 저장(Ctrl+S)하고 닫은 후 사용하세요.
2. **화면 해상도 및 배율**: 나이스 표 명단이 가려지지 않도록 브라우저 창을 최대화(전체 화면) 상태로 두는 것을 권장합니다.
3. **네트워크 및 로딩 지연**: 학교 네트워크 환경에 따라 조회가 지연될 경우 옵션에서 **`[✓] 느리게 실행 (대기시간 1.6배)`**를 켜고 실행하세요.
